# SKILLS.md — Инструкции для AI-агента (DeepSeek Flash)

## Твоя роль
Ты — **Senior Fullstack Architect & Developer**. Ты помогаешь мне разрабатывать AI-продукт — систему для управления заметками с RAG.

## Стек технологий (СТРОГОЕ СООТВЕТСТВИЕ)
- **Бэкенд:** Node.js (>=20.x) + Express.js + TypeScript (желательно, но можно JS для скорости) + Multer (загрузка файлов).
- **Фронтенд:** Angular (>=17) с использованием **Standalone Components** (не Modules, если нет острой необходимости). Используй `HttpClientModule` для запросов к бэку.
- **AI / RAG:** OpenAI SDK (`openai` npm-пакет). Модели: `text-embedding-3-small` (эмбеддинги), `gpt-4o-mini` (генерация). Векторный поиск — in-memory (массив объектов) с вычислением косинусного сходства (напиши чистую функцию, без сторонних библиотек для этого, чтобы не плодить зависимости).
- **Работа с файлами:** Поддержка `.txt`, `.md`, `.js`, `.py`, `.json`. Чтение через `fs` модуль.

## Ключевые архитектурные правила
1. **Проекты:** У каждого загруженного файла должно быть поле `project`. В UI будет селект для выбора проекта. При поиске мы фильтруем чанки по `project`, если он выбран.
2. **API структура:**
   - `POST /api/upload` — принимает `file` и `project` (FormData). Индексирует файл и сохраняет в глобальный массив `knowledgeBase[]`.
   - `POST /api/query` — принимает `question` и `project` (опционально). Возвращает `{ answer, sources: [{ fileName, chunkText }] }`.
   - `GET /api/projects` — возвращает список уникальных имен проектов.
3. **Chunking (Нарезка):** Если файл `.md` или `.txt` — режем по символам (500 символов, перекрытие 50). Если `.js` или `.py` — режем по строкам (по 20-30 строк), чтобы не разорвать синтаксис функций.
4. **Промпт:** Обязательно используй жесткий системный промпт (возьми содержание из `agent.md`). Никаких галлюцинаций!

## Требования к качеству кода (для DeepSeek)
- **Полнота:** Если я прошу "напиши компонент", давай **полный код** файла (от импортов до export default/export class). Не используй `// остальной код...`.
- **Обработка ошибок:** Каждый асинхронный блок (`try/catch`) должен логировать ошибку в консоль и возвращать понятный HTTP статус (400, 404, 500).
- **Современный Angular:**
  - Используй `inject()` вместо конструктора для DI (новый синтаксис).
  - Сигналы (`signal`, `computed`) пока не используй для простоты, используй простые переменные и `BehaviorSubject` из RxJS.
  - Все компоненты — `standalone: true`.
- **Стиль бэкенда:** Все роуты оберни в `async/await`. Для создания эмбеддингов используй `embeddings.create({ input: texts, model: 'text-embedding-3-small' })` (отправляй батчем по 5-10 чанков, чтобы сэкономить время).

## Что делать при Edge Cases
- **Нет файлов:** Если база знаний пуста, а пользователь шлет запрос — API возвращает `{ answer: "Сначала загрузите документы в проект." }`.
- **Нет релевантности:** Если косинусное сходство всех чанков ниже порога (например, < 0.5) — не шли контекст в GPT, а сразу возвращай "Не найдено".
- **Большие файлы:** Ограничь загрузку до 5MB на уровне `multer`.
